### data `bpy.types.IKParam.ik_solver`

IK solver for which these parameters are defined (default ``'LEGACY'``, readonly)

- ``LEGACY``
  Standard -- Original IK solver.
- ``ITASC``
  iTaSC -- Multi constraint, stateful IK solver.
