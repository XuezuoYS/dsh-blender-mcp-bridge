# 红线（自旧版 AGENTS.md 迁入）

> 旧版 `AGENTS.md` 是"AI 行为准则 + 设计说明"合一的文件，重写后只保留定位、基础安全需要、
> 类型安全、注释风格与 git 约束。**这里收留的是当时那些仍然有效、但没有归入新 AGENTS.md 的条目。**
>
> 与契约冲突时以 [`../docs/contract.md`](../docs/contract.md) 为准；本文件只说明"哪些做法被禁止"。

## 措辞红线

- **禁止**出现「安全沙箱」「已保护数据」「已完成保护」一类措辞。
- 安全相关位置必须**显式写出边界**，例如「**这不是安全边界，只防误操作**」。
- 引用上游安全声明必须**直接引原文**，不得改写成温和版本。
- **禁止**出现「本插件是一个 MCP 客户端 / 服务器」的表述：名字里的 `mcp` 指被连接的 **add-on**，
  链路里没有 MCP 这一层。

## 包管理与交付形态

- 包管理一律用 **pnpm**；不提交 `package-lock.json` / `yarn.lock`，锁文件是 `pnpm-lock.yaml`。
- 交付物是**纯 JS、零运行时依赖、无构建步骤**：不存在 `prepare` 脚本，
  因此不引入任何需要构建或安装授权的依赖。
- 本插件声明为 **profile bundle**，依赖由宿主 profile 的 pnpm workspace 提供；
  本仓库的 `node_modules` 只是开发期类型检查工具链。
- `package.json` 的 `files` 里**不得**列不存在的路径，也不得提前声明尚未实现的交付物。
- 配置键、工具名与返回字段名**一经发布不改**（新增可以，改名不行）。

## 来源标注

- 事实性结论必须标来源类别：**实测** / **源码** / **文档** / **规范**。
- **不得把推断写成实测**。上游 `data/api/` 与 `data/manual/` 的许可差异是必须如实标注的存疑项。

## 设置与用户上下文

- **未经用户要求不得修改**其渲染 / 导出设置（引擎、分辨率、采样、色彩管理、帧范围、
  输出路径与格式、合成节点组）。那是他按显卡、动画长度与后期流程调好的工作状态。
- 为探测临时改过的设置**必须还原**，包括 `frame_current` 这类容易被忽略的状态；
  还原点必须在**改动之前**读取，读不到的键一个都不写（不得用编造值兜底）。
- 漂移必须**可见**：`status.renderSettings` / `settingsBaseline` / `settingsDrift`、
  `exec.settingsDrift` 与 `warnings`。看到漂移非空就还原再继续。

## 基础安全的其余落点（AGENTS.md 三条细则的补充）

- 快照默认保留 **3 份**（`checkpoint.keep`），单份体积上限 `checkpoint.maxBytes` 可选；
  快照写盘失败 → **拒绝执行**，不得静默降级为"无备份继续"。
- **一轮任务 = 一个撤销点**：`undo_push` 每轮一次（`lib/checkpoint.js` 经 `ensureForTurn`）。
  需要更细粒度的撤销时，提示用户或拆成多轮，不要假装每步都能单独撤销。
- 任务目录位置 = 护栏 `allowRoot` 的位置。它在活动 `.blend` 同级时意味着
  "允许写工程目录下的一个子目录"——**这不是安全边界，只防误操作**。
- 只读工具**绝不创建任务目录**（`findExistingTaskDir` / `listTaskDirs` 都是纯只读）。

## 工具使用

- 文件内容一律用 `edit` / `write`；**禁止**用 shell 文本替换（`Add-Content` / `Set-Content` /
  `Out-File`）改写内容——非 UTF-8 控制台下会把中文损坏成无效 UTF-8，**不可逆**。
  确需批量改写时用 Node（显式 utf8 编解码），写回后逐个校验仍可解析。
- 一旦文件被写成无效 UTF-8，`read` / `write` 都进不去：**先在磁盘上删除**，再用 `write` 重建。
- 类型检查用 `pnpm check`；测试用 `pnpm test`。`diagnostics/**` 是**临时探针**，
  不入库、不进交付树、**豁免注释风格**（只保留首行 SPDX）。

## 注释风格的适用范围

- 遵循 AGENTS.md 的 JSDoc 规范：`lib/**`、`index.js`、`buildKnowledge.js`、`test/**`。
- `diagnostics/**` 豁免（临时脚本）；新写的 `.js` 一律首行 SPDX。
