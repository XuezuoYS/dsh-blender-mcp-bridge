## 安装验收（隔离 profile）

用临时 `DSH_HOME` 验证过全新 profile 的安装链路，不碰主人的 desktop profile：

1. `dsh --profile devcheck --from-default-profile web` 生成干净 profile；
2. 在 profile 的 `package.json` 加 `"dsh-blender-mcp-bridge": "link:D:/0-code-project/dsh-blender-mcp-bridge"`，并加进 `dsh.profile.bundles`；
3. `pnpm install` 后 `dsh --profile devcheck --dump-config`：**条目 `dsh-blender-mcp-bridge` 出现在组合树里**（bundle patch 生效）；
4. `dsh --profile devcheck --dump-config-schema`：插件条目 `status: "schema"`，说明模块解析、`schemastery` 与 `defineTool` 导入在真实宿主里都成立。
